# RING3 Invariants

Each rule is enforced in code and has at least one test. A rule may not be weakened to make something pass; stop
and report instead. Test names are the target; the card that first needs a rule writes its test.

| # | Rule | Enforced in | Test(s) | Card |
|---|---|---|---|---|
| 1 | **Model output is data, never code.** The model can only choose one action from a fixed allowlist of operations. Nothing a model returns is compiled, loaded, `eval`'d or executed. | `bridge/ring3bridge/strictjson.py`, op table | `test_inv_01_no_code_path` (grep/AST: no eval/exec/compile/subprocess on model text) | T-03a |
| 2 | **The kernel never trusts COM2.** Frames are bounded, COBS-decoded, CRC-checked and type-checked; anything else is dropped, counted and audited. ACTION bodies (fixed 16-byte structs) are parsed only in ring 3. No input on COM2 can panic or hang the kernel. | `kernel/core/agentlink.c` | `test_inv_02_frame_fuzz` (≥ 10,000 seeded malformed frames: 0 panics, heartbeat continues), `test_inv_02_kernel_never_parses_action` | T-03b |
| 3 | **Ring 3 can't reach ring 0 except through the syscall gate.** Kernel memory is supervisor-only; `CR0.WP` is set; only vector 0x80 has DPL 3; every user pointer is length-capped, overflow-checked and page-walked (every spanned page `P|U`, plus `W` for writes) before use; strings are length-bounded. | `paging.c`, `idt.c`, `uaccess.c`, `syscall.c` | `test_inv_03_user_cannot_touch_kernel`, `test_inv_03_bad_pointers` (null, kernel address, above `USER_TOP`, unmapped, wrap-around, read-only target, unterminated string, huge length → `-EFAULT`/`-EINVAL`), `test_inv_03_syscall_fuzz` | T-01 (slice), T-02 |
| 4 | **Capabilities are default-deny and fixed by the kernel at executor creation.** No syscall grants or changes capabilities; the model and the executor can't escalate. Runtime changes are kernel attenuations only (taint, E-stop). | `policy.c`, `proc.c` | `test_inv_04_default_deny`, `test_inv_04_policy_table` (every row of ARCHITECTURE §3 policy), `test_inv_04_no_escalation` | T-02 |
| 5 | **Destructive actions need a human "yes" on the console.** Confirmation is kernel-mediated, read only from COM1, defaults to no, and times out to no. The bridge has no path to COM1. | `confirm.c` | `test_inv_05_confirm_yes_no_timeout`, `test_inv_05_bridge_cannot_confirm` (bridge sends "y" frames: no effect) | T-02, T-03b |
| 6 | **A ring-3 fault kills only the executor.** CPU exceptions from CPL 3 end the executor and are audited; the kernel keeps running (lease checks, link, heartbeat) and the next request gets a fresh executor. | `idt.c` fault path, `proc.c` | `test_inv_06_fault_containment` (null deref, kernel write, `cli`, `hlt`, invalid opcode, div 0, stack overflow: each killed, uptime keeps advancing) | T-01 (slice), T-02 |
| 7 | **The agent is bounded.** At most 8 actions per request (counted in ring 0: the 9th ACTION ends the request, D-53), tick quotas per action (5 s of ring-3 time: time blocked in `agent_recv` or a confirmation does not count, D-58) and per request (120 s wall clock, D-58) enforced by the PIT, two invalid model replies → stop. An infinite loop in ring 3 can't stall the system. | `kernel/policy/`, `agentsh`, bridge | `test_inv_07_step_limit`, `test_inv_07_spin_preempted` | T-02, T-03b |
| 8 | **Model replies are validated exactly:** schema, one action, exact keys, bounded strings, no floats/NaN/duplicate keys/BOM/fences/trailing text, no lenient parsing, no repair. | `strictjson.py` | `test_inv_08_parser_cases` | T-03a |
| 9 | **Spending is reserved first and capped.** A reservation is logged before every model request; the run fails closed without a price or over `--budget-usd` or the project cap; the run stops at the first 401/403/transport error. Keys come only from `MODEL_API_KEY`, read only in `bridge/ring3bridge/models/`, and never reach logs, events, blobs, exceptions, fixtures, the screen or the repo. Agents never read `.env`. | `ledger.py`, `models/` | `test_inv_09_reservation_before_request`, `test_inv_09_no_secrets_anywhere`, `test_inv_09_stop_on_401` | T-03a (ledger), T-03b (adapter) |
| 10 | **Every run is logged and replayable.** Hash-chained event log containing the complete inbound event tape (console, COM2, COM3, timer events); `ring3 verify` detects any edit; `ring3 replay` feeds the tape through the host build of the same policy source and reproduces every decision, with no network, key or hardware. | `eventlog.py`, `replay.py` | `test_inv_10_chain_tamper`, `test_inv_10_replay_match` | T-03a (chain), T-05a (replay) |
| 11 | **Never claim more than the evidence shows.** Outcomes are DONE / REFUSED / STOPPED / ERROR plus the executed-operation list; never "success", "secure", "safe" or "real-time". The permissive build is always labelled. Costs are "estimate, not billing". | `agentsh`, README, screen text | `test_inv_11_banned_words` (scans user-facing strings and README) | T-04, T-05 |
| 12 | **A kernel panic is always a failure.** Panics only for kernel bugs (CPL 0 faults, broken internal invariants); every test run fails on `PANIC`. | `panic.c`, test harness | harness check in every QEMU test | T-01 |
| 13 | **Physical limits are enforced below the AI, twice.** The kernel driver enforces servo range/step/rate, fan duty/ramp, the presence interlock (fail closed on stale or missing sensor data) and the **E-stop latch** (motion capability revoked system-wide until a human resets at the console with the button released); the firmware independently clamps, cuts the fan in the E-stop interrupt, rejects bad frames, and goes to its halt state (fan 0) on its hardware watchdog or when the kernel goes silent. No process writes COM3 directly. The AI never writes or flashes firmware. | `device.c`, `ring3cell.ino` | `test_inv_13_limits` (kernel, simulated device on a socket), `test_inv_13_interlock_and_stale` (incl. no echo `0xFFFF` = not clear), `test_inv_13_estop_latch`, `hw`-marked: `test_inv_13_watchdog_safe_state`, `test_inv_13_estop_cuts_fan` (user present) | T-04 (kernel), T-06 (firmware) |
| 14 | **The camera witness only reports evidence.** Results are PASS / FAIL / CAN'T VERIFY; markers are found in every frame (no stale reference); anything uncertain is CAN'T VERIFY and is never upgraded; the witness never changes a kernel decision. | `bridge/ring3bridge/witness/` | `test_inv_14_cant_verify_cases` (markers missing, no mask, two masks, boundary band, bad calibration), `test_inv_14_not_in_decision_path` | T-07 |
| 15 | **Untrusted data attenuates authority.** Reading an untrusted object taints the executor for the rest of the request; while tainted, every energy-adding motion command (fan increase, servo move) and every write needs a human "y", on top of the hard limits; energy-reducing calls never prompt (D-50). Taint is never cleared by the executor or the model. | `kernel/policy/` | `test_inv_15_taint_forces_confirm`, `test_inv_15_taint_not_clearable` | T-02 |
| 16 | **Reducing energy is always allowed; adding it never bypasses the policy.** `cell_halt` and the kernel's own `AUTO_HALT` always go through, even under E-stop or taint; every motion command goes through `decide()`. The safety lease is evaluated on every timer tick, so a hazard is acted on even when no syscall is in progress. | `kernel/policy/`, `device.c` | `test_inv_16_halt_always`, `test_inv_16_tick_lease_autohalt` | T-04 |
