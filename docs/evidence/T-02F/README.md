## Decisions made in this card (documented, not in the card text)
- A fan decrease never prompts at all, including the first-fan prompt (`fan_confirmed` is reset per request, so a
  fan left running by the previous request could otherwise prompt on being turned down). D-50 says "any fan
  decrease never prompts"; INV-16 is the tie-breaker.
- `cell_fan(0)` keeps audit reason `none` (as before); `cell_halt` keeps `halt`. Both still update
  `fan_change_tick` when the duty was non-zero, so the 1 s rate rule applies to the next increase exactly as
  in T-02.
- Test-image knobs added (never in production images): `confirmrace on|off` (F4) and
  `teletick <mm> <estop> <n>|off` (F5: a telemetry record from the tick IRQ every n ticks, the shape T-04's
  COM3 driver will produce). `exit` prints `audit: dropped=N` in every image.
- Drain bounds: 4 records per syscall return (each call produces at most one), 2 per tick from ring 3.
  Output on `-serial stdio` is not baud-paced by QEMU here (4,800 audited calls per second were observed),
  so the bounds are about keeping interrupt latency bounded, not throughput.
