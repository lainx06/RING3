| D-39 | 2026-11-01 | L | **Hardware facts that change designs, found in review.** (a) QEMU's ISA serial defaults wire **COM3 (0x3E8) to IRQ 4, shared with COM1** (COM2 0x2F8 IRQ 3; check in T-01B). The COM3 driver drains its receive FIFO fully in the IRQ 4 handler, and **also polls COM3 on every PIT tick** as a backstop; COM1 stays polled with IER = 0. (b) **Uno pin budget is tight:** 18 usable I/O pins (D0/D1 are USB serial) and the cell needs about 17 (LCD 6, L293D 3, servo 1, HC-SR04 2, E-stop 1, buzzer 1, RGB 3). The Servo library uses Timer1, so D10 can't do PWM; fan PWM goes on D5, D6, D3 or D11; RGB uses plain digital pins (no colour mixing needed). T-06 writes the pin table first. (c) **Webcam capture defaults to a small Windows-side helper** that hands stills to the bridge; WSL2's stock kernel probably lacks the USB video class driver `[UNVERIFIED]`, 2-minute check in T-07, don't build a custom kernel. (d) If WSLg isn't available, QEMU's `-display curses` shows the VGA text screen in a terminal. | Each of these would otherwise surface on Nov 3, the busiest day. |
