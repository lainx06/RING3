## Do
1. **Link ABI first (M1, commit it early: T-03b builds on it).** `abi/link_abi.h` (freestanding C, no includes
   beyond `<stdint.h>`) **and** `bridge/ring3bridge/abi.py`, plus `docs/LINK_ABI.md`: frame types and numbers
   (ARCHITECTURE §4), the decoded-payload layout, max sizes, the **16-byte ACTION struct** (`op u8, flags u8,
   p1 i16, p2 i16, nonce u32, text_id u8, rsv[5]`), op numbers for the complete allowlist (`cell_status`, `fan_set`,
   `servo_set`, `halt`, `lcd_show`, `list_objects`, `read_object`, `write_object`, `witness`), `TEXT`, `FINAL`
   (`DONE`/`REFUSE`), `STOP` reasons, the `OBSERVATION` layout, `HEARTBEAT`, `AUDIT`, `EVENT`. **D-52 additions:**
   the **object table with integer IDs**, read (read-only) from `kernel/core/objstore.c` (`read_object`/
   `write_object` carry the ID in `p1`); **exact body-length bounds per frame type** (`ACTION` exactly 16 B; `TEXT`,
   `FINAL`, `REQUEST`, `OBSERVATION` with their §4/§6 limits); the maximum decoded frame = 7 + max body and the
   matching maximum encoded (COBS) length; **every unused field and `rsv[5]` must be zero**; and **a `TEXT` frame is
   always sent before the `ACTION` that references it**. A test parses the C header and fails if any constant
   differs from `abi.py`.
2. **Framing.** COBS + CRC-16/CCITT-FALSE + the §4 payload layout; incremental decoder that resynchronises on
   `0x00`; bounded buffers (raw input capped at the maximum encoded length); rejects non-canonical COBS, any frame
   whose decoded length isn't exactly `7 + len`, and any body outside its type's bounds; returns typed frames or a
   typed error (never raises on bad input). Tests: the shared
   vectors in `firmware/test/link_vectors.txt` (byte for byte), check value `0x29B1`, round trips, every malformed
   class (`--inject` list in §6).
3. **Strict JSON (INV-08).** Exactly the §6 schema: one of call/done/refuse; exact keys per op; integers only
   (no bools, floats, NaN, exponents); `duty` 0–100, `deg` 0–180, `line` 0–1; printable-ASCII strings with the §6
   byte caps (`lcd_show` text ≤ 16 B, object text ≤ 64 B, `summary`/`reason` ≤ 200 B);
   `name` from the object table; reject duplicate keys, extra keys, BOM, code fences, leading/trailing text, more
   than one JSON value. No repair, no lenient parsing. `test_inv_08_parser_cases` with ≥ 60 cases, including
   adversarial ones (nested objects, unicode tricks, huge numbers, `"duty": 60.0`, `"duty": "60"`).
   The bridge does **not** apply device limits (the kernel does); out-of-schema ranges are rejected here only as
   malformed.
4. **ACTION serializer.** Validated call → a `TEXT` frame first when the op has text, then one 16-byte `ACTION`
   with all unused bytes zero. The `nonce` is **deterministic** (D-52): derived from a per-run seed recorded in
   `run_start` and the action's sequence number, so recorded replies re-serialize byte for byte. Round-trip tests
   against `abi.py`.
5. **Spend ledger (INV-09).** Integer µUSD. `config/models.toml` holds the model ID (`muse-spark-1.3`, D-06) and
   **price per input/output token, which must come from Meta's official pricing page**: look it up; if you can't
   verify it from an official source, leave the price unset and mark it `[UNVERIFIED]` (the ledger then fails
   closed, which is correct). `config/budget.toml` project cap $30 (D-12). Every model request is preceded by a
   logged reservation sized for the worst case (max output tokens); over `--budget-usd` or the project cap, or no
   price → refuse before sending. **Reservation size (D-52):** input tokens counted as **1 per UTF-8 byte** of the
   whole request (no tokenizer guesses) plus the request's max output tokens; **unsettled reservations count
   against both caps** until settled. Tests use a **synthetic price fixture**; a separate test proves the shipped
   config with the price unset fails closed. `ring3 spend` prints the total, labelled "estimate, not billing".
6. **Event log (INV-10).** `runs/<run_id>/events.jsonl`: canonical JSON (sorted keys, no spaces, integers only,
   D-15), each record chained by `prev` + `h` (SHA-256), blobs content-addressed under `runs/<run_id>/blobs/`.
   Record types exactly as ARCHITECTURE §6 names them (`audit` for decoded kernel audit records), plus `event` for
   decoded `EVENT` frames. `ring3 verify <run>` checks the chain **and recomputes the SHA-256 of every blob**, and
   that every blob referenced in the log exists and matches → `CHAIN OK` or the first broken record or blob.
   `test_inv_10_chain_tamper` edits one byte in the log and, separately, one byte in a blob.
7. **Model adapter behind a transport interface.** `bridge/ring3bridge/models/` is the **only** place
   `MODEL_API_KEY` is read (env only; never `.env`). Muse Spark via `POST https://api.meta.ai/v1/responses` (D-06):
   take the request/response field names from Meta's official API docs; anything you can't verify is
   `[UNVERIFIED]` in the code and the report. The key lives **only inside the transport layer**: `model_request`
   records hold header-free metadata, and exceptions are scrubbed of headers before they propagate. Stop at the
   first 401/403/transport error.
   Tests use a **fake transport only**: `test_inv_09_reservation_before_request`, `test_inv_09_stop_on_401`,
   `test_inv_09_no_secrets_anywhere` (scans logs, events, blobs, exceptions, fixtures for a sentinel key).
8. **Context pack v1.** `docs/context-packs/agent-v1.md`: the model's role (maintenance technician for a work cell
   run by a kernel it can't override), the op allowlist with exact JSON shapes, the cell and its limits as of
   D-47 (fan 0 or 50–80 %, servo 30–150°), the object table, "one action per reply, JSON only", how observations
   arrive (labelled untrusted data), and that refusals and halts are acceptable outcomes. No claims the kernel
   doesn't enforce. Its SHA-256 goes in `run_start`.
9. **INV-01.** `test_inv_01_no_code_path`: AST/grep check that nothing in `bridge/` passes model text to
   `eval`/`exec`/`compile`/`subprocess`/`pickle`/`importlib`.
10. **CLI.** `uv run ring3 verify|spend|frames-selftest` (+ stubs for `run`, `replay`, `fuzz-link` that say
    "T-03b"/"T-05a").
