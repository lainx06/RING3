1. **F1 Lost quota kill (HIGH).** A tick that sets `kill_pending` while the CPU is in ring 0 outside the confirm
   loop must still end the executor. Either check `exec_kill_pending()` at the end of `syscall_dispatch` (and any
   other ring-0 path that returns to ring 3) and abandon, or never `sti()` inside syscall handling. Pick one, say
   why. Test: a program whose syscalls force an audit flush right as the quota expires still ends with `LIMIT`, and
   the next request runs normally.
2. **F3 Energy-reducing calls (MEDIUM; order fixed by D-52).** In `decide()`: check "inside a request" first;
   then evaluate `cell_halt` and `cell_fan(0)` **before** the pending/killing gates. They need **no capability**
   (D-50), aren't affected by taint, E-stop, stale data or presence, never prompt, set the commanded duty to 0, and
   **leave any pending confirmation as it is** (state otherwise unchanged). A fan **decrease to a non-zero duty**
   keeps **every** other gate (pending, killing, `CAP_DEV_MOVE`, E-stop, stale, presence, the 0-or-50–80 % range →
   `DENY_ARG`) and skips **only** the ramp rule and the taint confirmation (D-50: INV-16 wins over the taint prompt
   for energy-reducing calls); servo moves still prompt when tainted. Host tests: halt and fan(0) with a pending
   confirmation (pending preserved), after `LIMIT`, under E-stop, tainted, and without `CAP_DEV_MOVE`; a tainted
   80→60 decrease is allowed without a prompt; a decrease to 60 with a hand present or stale data → denied; a
   decrease to 40 → `DENY_ARG`; a tainted servo move still prompts.
3. **F4 Confirm race (MEDIUM; D-52).** A console line that is ready is **always consumed** and passed to `decide()`
   as an event (never left in the buffer to answer a later prompt); if the timeout tick already cleared `pending`,
   `decide()` records it as a stray answer with no effect. The timed-out call returns `-ECANCELED`; a `DEC_NONE`
   decision never maps to a non-negative result. QEMU tests: a line arriving in the same wake-up as the timeout tick
   → `-ECANCELED`, audit `CONFIRM_NO`, and the **next** prompt is not auto-answered by that line; kernel-vs-host
   replay still matches.
4. **F5 Audit/tape drain (MEDIUM; D-52).** Fix `serial_putc` so `line_start` is true after the `\r\n` pair. Drain
   a bounded amount per tick and per syscall return, without opening interrupts inside syscall handling (consistent
   with F1). **Never drop:** when the ring is full inside a syscall, drain synchronously (polled, interrupts still
   off) until a record fits. **`dropped > 0` fails every QEMU test.** The syscall fuzzer and F1's quota test must
   pass with `dropped == 0` within the suite time limit (keep COM1 tape printing off in the fuzz test as T-02 did;
   the audit sink still gets every record).
5. **F7 Aliasing in `lease()` (LOW).** Copy the duty to a local before mutating `n`; host test that a
   telemetry-path `AUTO_HALT` records the duty that was running.
6. **F8 Quota arguments (LOW).** `EXEC_START` with a zero or negative quota → `DENY_RULE`; no "0 means unlimited".
